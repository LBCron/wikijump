# SCP-JP manual publication set

This directory holds the candidate source files and shared components for manual transfer to SCP-JP. No public Wikidot writes have been made.

[FINAL-PUBLICATION.md](FINAL-PUBLICATION.md) is the page, dependency-order, and attachment checklist. [final-manual-publication-set.json](final-manual-publication-set.json) is its machine-readable form, and [dependency-graph.json](dependency-graph.json) records the dependency order.

Before an update, confirm the live SCP-JP target still matches the listed revision. Publishing requires explicit operator authorization.
